# מבחן אנטומיה - מוח (תוסף Chrome ל-Complete Anatomy)

תוסף שמוסיף כפתור לאתר [completeanatomy.app](https://completeanatomy.app) ומאפשר לתרגל את עצמך על רשימת האיברים למבחן: התוסף בוחר איבר אקראי מהרשימה, **מסמן אותו על המודל התלת-ממדי** (מבודד אותו כדי שייראה ברור), **מסתיר את שמו בטשטוש**, ולחיצה חושפת את השם. יש כפתור "המשך" למעבר בין האיברים בלי חזרות, עם מונה התקדמות.

## התקנה (פעם אחת)

1. פותחים ב-Chrome את הכתובת: `chrome://extensions`
2. מדליקים למעלה-מימין את **מצב מפתח / Developer mode**.
3. לוחצים **טעינת פריט לא ארוז / Load unpacked**.
4. בוחרים את התיקייה של הפרויקט הזה (התיקייה שמכילה את `manifest.json`).
5. נכנסים ל-[המודל של המוח](https://completeanatomy.app/models/964db2dd4f98052f03baa9ca5f2dbcae?bodyRegion=3) (צריך להיות מחוברים לחשבון Complete Anatomy). **מרעננים** את הדף פעם אחת אחרי ההתקנה.

## שימוש

1. מופיע כפתור **"בחן אותי"** למעלה במרכז המסך.
2. לוחצים עליו ובוחרים:
   - **כל האיברים** - מבחן על כל האיברים הזמינים.
   - **בחירת איברים** - סימון אילו איברים לכלול (מקובצים לפי ניתוח).
3. **התחל מבחן**. לכל שאלה: האיבר מסומן על המודל ושמו מטושטש. חושבים על התשובה, לוחצים על המלבן המטושטש כדי לחשוף את השם, ואז **המשך**.

## כיסוי - חשוב לדעת

הרשימה המקורית ([`dissections.md`](dissections.md)) כוללת **295 מונחים**, אך **המודל הספציפי הזה כולל רק חלק מהם כמבנים נבחרים** (אפשר ללחוץ עליהם). כל מונח אומת מול מנוע החיפוש של Complete Anatomy - גם בשם האנגלי וגם בשם הלטיני (Terminologia Anatomica):

- **120 איברים** קיימים במודל וזמינים לתרגול.
- השאר (בעיקר ג'ירוסים/סולקוסים קורטיקליים עדינים, אינסולה, קפסולות, מסלולי חומר לבן וגרעיני גזע-מוח) **פשוט אינם מבנים נפרדים במודל הזה** - כלומר גם ידנית אי אפשר ללחוץ עליהם שם. אלה מסומנים ב-`excluded` בקובץ [`src/structures.json`](src/structures.json).

**נבדק לעומק שההיעדרות אמיתית ולא עניין של תצוגה:** גם עם כל 12 המערכות פעילות וכל השכבות (Layers) במקסימום העומק, החיפוש עדיין מחזיר ריק למבנים האלה. בנוסף, כל ה-Regions וה-Systems ב-Complete Anatomy (Full Body, Head & Neck, Nervous וכו') הם תצוגות/פילטרים על **אותו model_id יחיד** (`964db2dd…`), והחיפוש מכסה את כולו - כלומר אין תצוגה או מודל אחר באפליקציה שכן מכיל אותם. זו מגבלת הסגמנטציה של Complete Anatomy עצמה. (הוכחה: מבנים עמוקים כמו Thalamus/Putamen כן נמצאים גם ב-Layer 1, אז החיפוש אינו מוגבל לנראות.)

כיסוי לפי ניתוח: ניתוח 1: 23, ניתוח 2: 50, ניתוח 3: 19, ניתוח 4: 28.

## איך זה עובד (למפתח)

- החיפוש של האתר הוא server-side: `GET https://apigw.healthcare.elsevier.com/h/eca/apigw/search/wc?s=<query>&model_id=<id>&version=444&lang=en`, ומחזיר JSON של מבנים עם `cid` (מזהה), `name` (אנגלית) ו-`sname` (לטינית).
- התוסף מנהיג את פאנל החיפוש המובנה של האתר (מזין שם, לוחץ על השורה לפי `data-testid="structure-item-<cid>"`), ואז לוחץ **Isolate** כדי להציג את המבנה לבד וברור בכל מצב מצלמה.
- כדי לא לחשוף את התשובה, התוסף מסתיר את רכיבי ה-UI של האתר שמציגים את השם: פירורי-הלחם (breadcrumb), כרטיס המידע, וכותרת ה-Isolate.

## מבנה הקבצים

- `manifest.json` - הגדרות התוסף (MV3).
- `src/api.js` - שכבת האינטגרציה עם האתר (בחירה, בידוד, הסתרת ספוילרים).
- `src/quiz.js` - מנוע המבחן (ערבוב ללא חזרות, התקדמות).
- `src/ui-setup.js` / `src/ui-quiz.js` - ממשק (כפתור, מודל בחירה, פאנל מבחן).
- `src/content.js` - חיבור הכל בטעינת הדף.
- `src/styles.css` - עיצוב תואם לקו של האתר.
- `src/structures.json` - **מפת המונחים המאומתת** (מונח → cid + שם במודל) + רשימת המוחרגים.

## עדכון/בנייה מחדש של המיפוי

`data/terms.json` הוא רשימת המקור. `data/collected.json` ו-`data/inventory.json` הם תוצרי הסקירה של מנוע החיפוש. הסקריפטים ב-`scripts/` מצליבים ומייצרים את `src/structures.json`:

```bash
node scripts/resolve.mjs
```

(ראו [`scripts/syn.json`](scripts/syn.json) למפת הסינונימים בין השמות ברשימה לשמות במודל.)
